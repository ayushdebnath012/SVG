# ReSolve mechanical CAD paper

Current title: **ReSolve: Instruction-Guided 3D CAD Editing with Geometry and View Evaluation**.

The active manuscript uses the online BenchCAD edit release, a disclosed local family/template-disjoint split, fresh-model training, and native STEP geometry evaluation. It also distinguishes the earlier localized drawing pilot and deterministic truss/plate controls. All six illustrated mechanical edits have FEM attempts under disclosed synthetic material/load/fixture contracts; five source/target/prediction triples solve, while the screw case remains unverified after meshing fails. The full benchmark has no physical operating contracts.

- `main.tex`: entry point; `sections/mechanical/`: active sections.
- `mechanical-results.tex` and `cuda-results.tex`: generated from completed local evaluation artifacts.
- `figures/benchcad-reference-pairs.svg`: editable source/released-target illustrations, not predictions.
- `../../reports/BENCHCAD_ONLINE_TRAINING_AND_PAPER_20261002.md`: data, training, evaluation and limitations.

Build in this directory with `tectonic main.tex --keep-logs`, or XeLaTeX/BibTeX. The legacy directory name is retained. The previous manuscript is archived at `../archive/resolve-network-20261001-before-mechanical/`. This is a working draft, not an official BenchCAD leaderboard submission.

Builders: `../../scripts/build_mechanical_paper_diagrams.py` and `../../scripts/build_fem_explanation_figures.py`.

The main-method architecture uses `figures/cad-fem-illustrated-architecture` (Figure 2), generated by `../../scripts/build_cad_fem_architecture_figure.py`. It combines actual source/predicted flange CAD views, saved mesh/stress fields and schematic CAD-model modules.

The main illustrated example changes a flange from four to six mounting holes, preserving hole diameter and bolt-circle radius. New drawing and large FEM sheets use this functional edit rather than the shaft pose transformation. Historical benchmark pose-edit results remain in their original evidence tables.

The CVPR-oriented revision leads with the completed two-source 3B experiment and adds common-camera silhouette/source-relative edit-mask evaluation. Earlier single-source runs and deterministic structural controls are supplementary. The new `cad-edit-localization` figure uses actual saved flange solids.
