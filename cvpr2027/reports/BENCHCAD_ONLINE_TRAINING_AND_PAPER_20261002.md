# Published online CAD editing benchmark and completed training

2 October 2026. The active paper now focuses on mechanical CAD editing and linked
SVG views; resistor and pipe experiments remain only in the archived prior draft.

## Online data and split

Used [BenchCAD's published edit pairs](https://huggingface.co/datasets/BenchCAD/BenchCAD),
revision `5919f578ab09ec283603a082fab07c7639ab56eb`, CC-BY-4.0, Zhang et al. 2026.
748 released pairs; 38 pipe/circuit-related records excluded, leaving 710.
Whole families are connected by shared numeric-masked source/target AST templates
before a deterministic hash-ranked component split. The split contains 533/50/127
train/validation/test pairs. Full chat <=3072 tokens and target <=512 tokens retain
492/44/126. All 48 omissions are recorded; no sample was silently truncated.

This repurposes an author-designated held-out benchmark as a locally partitioned
training/evaluation corpus. It is not an official BenchCAD score. No previous
mechanical adapter is reused; test families/components are excluded from training.
Cross-dataset geometric ancestry and model-pretraining contamination are not proven.

Original instructions are preserved. Targets are line patches between normalized
published programs, rather than locally generated numeric instructions with gold
line hints. The normalization audit checks 1496 executable ASTs; four docstring
whitespace changes are disclosed. Every gold patch replays exactly. Split hashes,
family/component isolation, native STEP hashes and source IDs are checked.

## Completed local model

MLX QLoRA, fresh 4-bit Qwen2.5-Coder-1.5B-Instruct, revision
`b3252a2f97102b1fb1571fec2c9b27219a8536be`, Apple M5 / 16 GB. Seed 17, one pass
(492 optimizer iterations), batch 1, learning rate 1e-4, prompt-masked loss.
Last eight transformer blocks; rank 8, scale 20, dropout 0, all attention and MLP
linear projections. The final adapter was reloaded before full held-out evaluation.

| System / all 126 retained cases | Applicable patch | Target AST | IoU >=0.95 | IoU >=0.99999 |
|---|---:|---:|---:|---:|
| Base, strict schema | 0 | 0 | 0 | 0 |
| Base, bare-list transport control | 56 | 0 | 1 | 0 |
| One-pass MLX QLoRA | 77 | 12 | 18 | 12 |

The transport control only wraps a bare list in the required JSON object; no
coordinates, insertions or deletions are repaired. Its three valid solids yield
one broad match. The trained model builds 39 valid solids, with 37 execution
errors and 49 invalid patches. There are no scoring timeouts or Boolean-comparison
errors. The remaining case is an invalid upstream reference.

Strict geometric success is 12/125 valid references (9.6%), or 12/126 tasks as a
raw all-task count. Target AST matches concentrate in T1 (11/31) and T2 (1/18).
T3, T4 and T5 have no exact target AST matches in this run. The small model has a
substantial remaining content/coordinate gap, not just a wrapper-format mismatch.
IoU can miss small but essential feature errors; engineering tolerance or preserved
constraints are not certified by this volume metric.

## Source-quality limits

One held-out rivet STEP is not a valid positive-volume solid under the local CAD
kernel, so it is excluded from the geometric success denominator rather than
called a model failure. All task outputs remain visible.

`topup_stepped_shaft_top_slot_rev` asks to cut an obround blind slot, while its source
already has `slot2D(...).cutBlind(...)` and its supplied target deletes that feature.
This concrete instruction/target conflict is recorded, not silently relabeled.
Published supervision is retained for reproducibility; scores measure reference
agreement, not verified instruction correctness for every row. A broader semantic
label audit is still needed. No claim is made that every reverse-edit record is wrong.

FEM is not evaluated for BenchCAD mechanical edits because materials, units,
supports, loads and analysis contracts are absent. Historical axial-truss FEM and
plate-clearance controls are reported separately and are not learned CAD results.

## Additional completed H100 training

A subsequent server run uses a fresh, unquantized BF16
`Qwen/Qwen2.5-Coder-1.5B-Instruct`, pinned model revision
`2e1fd397ee46e1388853d2af2c993145b0f1098a`, on one NVIDIA H100 NVL.
It trains the identical 492 retained chat records for three epochs / 1,476
optimizer updates, with the same 44 validation and 126 test records. File hashes
and test-ID order were checked. Rank 8, alpha 160 (scale 20), zero dropout,
last eight transformer blocks, seven attention/MLP projections, batch one,
seed 17 and learning rate 1e-4 are recorded. Final saved weights are reloaded
for greedy 512-token evaluation; no test-based checkpoint selection is used.
Training plus final evaluation takes 502.7 seconds; peak allocated GPU memory
is 7,937,536,512 bytes. Existing server workloads were left running.

The adapter has 2,637,824 trainable parameters and 112 finite saved tensors.
Adapter SHA-256: `0e3d20490f477a3f4e61b09fb14f82b286cf5240ad96d82b91e5e4b9961547e2`.
Artifacts, training logs, manifest and raw server predictions are saved in
`runs/benchcad-online-h100-20261002/`. Only reference STEP paths are remapped
for local scoring; unchanged remote prediction files are retained separately.
The changed precision, software implementation and epoch count preclude an
isolated hardware-effect comparison or a preregistered confirmation claim.

The completed CUDA comparison is:

Strict success is 15/125 valid released references (12.0%). The trained outputs

generations. Improvement remains limited and does not establish reliable complex
engineering editing or physical validity.
