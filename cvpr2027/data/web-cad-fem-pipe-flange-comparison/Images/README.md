# Evidence Images

Screenshots are grouped by purpose and named by the engineering content they document.

- `CAD/` — CAD sketches, drawings and assembly
- `Setup/` — Workbench, material, topology, contacts, named selections, supports and loading
- `Mesh/` — mesh sizing, generated mesh and mesh-quality checks
- `Results/` — deformation, stress and reaction-force results

The filenames use the terminology and numerical values documented in the project report.
