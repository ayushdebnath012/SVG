# FKDC-Rear-Axle
This repository involves a SolidWorks model of Rear Axle of a FKDC GoKart. Alongwith this, it also contains ANSYS .wbpz files of its Torsion, Static Loading and Lateral Loading analysis.


For opening the ANSYS analysis double click on .wbpz file and let Ansys Workbench open. 
There you will find three analysis named Torsion, Static Loading and Lateral Loading. 
Now double click on result of any of those which you want to open. 
You will observe that Static Structural will open, there right click on mesh and select clear generated data. 
After doing so resolve the model and you will be able to see the analysis which I performed.

For more clarification you can also check out a pdf named Handwritten Calculations in which i have done all calculations by hand(IGNORE HANDWRITTING).
