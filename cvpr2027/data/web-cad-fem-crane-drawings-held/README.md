# Crane Hook Assembly – Autodesk Inventor

## 📌 Project Overview
This repository contains a **Crane Hook Assembly** designed and assembled using **Autodesk Inventor**.  
The project includes individual part modeling, full assembly, exploded view, and detailed engineering drawings.

This assembly was created as part of a **CAD design examination / academic project**.

---

## 🛠 Software Used
- Autodesk Inventor Professional
- ISO Standards for fasteners and dimensions

---

## 📂 Project Contents
- **Parts (.ipt)** – All individual components modeled with correct dimensions and materials  
- **Assembly (.iam)** – Fully constrained crane hook assembly  
- **Drawings (.idw & .pdf)** – Part drawings and assembly drawings with annotations  
- **Exploded View** – Assembly explosion for better understanding of part relationships  

---

## ⚙ Assembly Details
- Proper constraints applied (Mate, Insert, Flush)
- Correct material and appearance assigned
- ISO standard fasteners used
- Exploded view created for assembly clarity
