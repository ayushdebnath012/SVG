7.5. Postprocessing

7.5.1. Total Deformation

Follow these steps to create a deformation plot using the Total Deformation object:

  1. In the tree Outline, right-click Solution and select Insert. Select Deformation, then click Total.

  2. Switch to the Display tab, then select Thick Shells and Beams in the Style group.

  3. Right-click Total Deformation object and select Retrieve This Result to visualize the plot.

    Note:  The default deformation scale is 1.2 (Auto Scale). You can view and change this by navigating to the Display group of the Result tab.

 

7.5.2. Stress Plot

In the Mechanical application, you can create stress plots for the composite model and individual Analysis Plies. You can also view the stress value at any point or locate the minimum/maximum value on an object. Finally, it is possible to view different plot results when you insert another stress type or change the component.

In the following example, the Normal Stress across the Fiber’s X-direction for the bottom Analysis Ply will be evaluated:

  1. In the Tree View, right-click the Solution group and select Insert > Stress > Normal Stress.

  2. In the Details panel of the Normal Stress object, select the undefined Ply field. Then, expand the Imported Plies group, select the bottom ply of the structure (P1L3_ModelingPly.1(ACP(Pre)), and click Apply to define that selection field.

  3. In the Details panel of the Normal Stress object, expand the list of the Coordinate System field and select the Fiber Coordinate System for postprocessing.

  4. To postprocess the result, right-click the Normal Stress object and select Retrieve This Result.

  5. You can use the Probe tool from the Result tab to select a specific node and evaluate the result.

    Tip:  You can change the stress type and component by modifying Type and Orientation in the Details panel of the Stress object.

 

7.5.3. Composite Failure Tool

Similar to stress plots, failure plots enable you to examine the failure result of the whole structure, separate layers, or individual elements. You can also examine the failure modes, check on which plies the critical failures occur, and modify the plot legend.

Follow these steps to create a failure plot using the Composite Failure Tool object:

  1. In the tree Outline, right-click Solution and insert a Composite Failure Tool under Composites.

  2. In the Details pane, switch Maximum Stress and Core Failure to On (A). In the Worksheet pane, configure the Maximum Stress and Core Failure properties as shown in the image below (B).

  3. Expand Composite Failure Tool under Solution to check the Inverse Reserve Factor.

  4. Right-click Inverse Reserve Factor and select Retrieve This Result to view the Composite Failure plot.

    Note:  You can use probes to identify result quantities at any point or locate the minimum/maximum value on an object. To do the former, select the result plot of interest, then go to the Result tab, click the Probe icon, and hover over the plot to obtain the result values. You can also click the object to create a probe annotation for the location of interest. To do the latter, go to the Result tab, click the Maximum and/or Minimum icon in the toolbar, and then select the result plot of interest.

Tip:  Similar to the workflow for the Normal Stress result, you can enable Ply as the method of the Sub Scope By field to view the failure results layer by layer.

Next, you can visualize the results in a 2D projection of the structure and evaluate the failure modes and critical layers:

  1. Navigate to the Display tab and disable the Thick Shell and Beams option.

  2. In the Details panel of the Inverse Reserve Factor result object, activate the Show Critical Failure Mode field by setting it to Yes.

  3. Evaluate the result to see the failure modes in the model.

7.5.4. Composite Sampling Point Tool

To create a through-the-thickness plot to analyze a particular sampling point, follow these steps:

  1. Select the Composite Failure Tool group, right-click, and select Promote to Composite Failure Criteria. This will create a group named Composite Failure Criteria Definitions under the Model in the Tree View, which contains the user-defined Composite Failure Criteria objects.

  2. Right-click the Solution group and select Insert > Composites > Composite Sampling Point Tool (A, below).

    In the Details panel of the Composite Sampling Point Tool (B), set the Composite Failure Criteria field (C) to the newly promoted Composite Failure Tool's criteria.

  3. Switch to the Composite Sampling Point object (A), click the undefined Geometry field (B), select a point in the Model (C), and click Apply (D). The white cross (E) represents the location of the selected Sampling Point which can also be seen under the Scope group of the object (F).

  4. After evaluating the result, you can view the Worksheet of the object and select which items to postprocess. To analyze the results for the selected Sampling Point, enable the items shown below.
