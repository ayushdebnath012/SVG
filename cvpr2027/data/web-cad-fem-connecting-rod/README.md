# Project Overview

This project presents the design and structural analysis of a mechanical connecting rod using **SolidWorks** for 3D CAD modeling and **ANSYS Workbench** for Finite Element Analysis (FEA).

The objective was to evaluate the structural performance of the connecting rod under static loading conditions by analyzing stress distribution, total deformation, and equivalent elastic strain. This project demonstrates the complete engineering workflow from CAD modeling to CAE validation.

---

# Project Objectives

- Design a 3D Connecting Rod in SolidWorks
- Import the CAD model into ANSYS Workbench
- Generate a high-quality finite element mesh
- Apply appropriate material properties and boundary conditions
- Perform Linear Static Structural Analysis
- Evaluate Von Mises Stress
- Evaluate Total Deformation
- Evaluate Equivalent Elastic Strain
- Verify structural safety
