# Published cycloidal gearbox CAD + FEM

One assembly family with 15 component-study groups and 28 primary saved references: 15 PLA/steel, 13 PETG-CF. All 28 native FreeCAD models import as valid single-solid BREP; original assembly STEP imports with 198 solids and 3455 faces. Complex housing, lid, flanges and disk coexist with simple pins and rings. This is component linear statics, not an assembly contact/dynamic model.

31 original saved solutions include 28 primary references, two earlier axial cam solutions and one underloaded disk. One additional housing FRD has mesh only, no solved fields. All source files and their corrected/uncorrected load decks remain untouched. Native result objects may retain older runs; verified selected objects and raw FRD are listed in catalog.json. Exact NPZ arrays preserve source IDs and saved decimal values. Derived von Mises is labeled and consistent with native result arrays. No numerical model score has been measured and zero cases are certified.
