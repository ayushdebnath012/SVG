## Geometric Specifications

| Parameter | Value |
|---|---:|
| Wing Span (b) | 10.92 m |
| Root / Mean Chord (c) | 4.87 m |
| Planform Area (S) | 56.95 m² |
| Internal Architecture | Multi-rib, two-spar wing box |

The wing box consists of a multi-rib and two-spar internal structure. The geometry was used for the structural FEA models using ANSYS shell elements, including `SHELL181` and `SHELL281`.

The CAD geometry is provided in IGES format so that it can be imported into compatible CAD and FEA software for further analysis.
