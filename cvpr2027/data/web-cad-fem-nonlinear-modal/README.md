# Published CAD/FEM nonlinear and modal extension

14 CAD/reference candidates: five native FreeCAD examples with saved FEM fields and nine STEP modal specimens with numerical FEM frequency targets. Five native examples represent spanner, intersecting tubes, stacked beams, an idealized soil-cutting body and an embankment/ditch. Geomechanics is labeled separately. Nine modal specimens comprise three uniform and six stepped plates, not nine unrelated complex engineering families. Two auxiliary STEP files (tensile coupon and printer calibration cube) are excluded. No dimensioned engineering drawings verified.

## Original sources

Harry van Langen, fcFEM-basic: https://github.com/HarryvL/fcFEM-basic. Original CAD, VTK fields, source parameter files, license text and revision/SHA256 manifest downloaded. Five valid native CAD shapes; finite saved displacement arrays in 42 embedded result objects and seven external VTK exports. Outputs/increments are not additional cases. Parameter files request incremental displacement via negative out_disp; verify each saved result's interpretation and load factor before scoring. These files are examples for the publisher's elastoplastic collapse solver, not certified collapse-load references. Software LGPL declaration retained; source-data scope not assumed.

Original source workbook/formulas/cached values untouched. Source README sheet names do not match actual workbook; Test4 filename fef50 also conflicts with table association fef75. Keep material, specimen dimensions, formulation, clamped length and orientation consistent before scoring. Repeated Thin Shell headers retained as separate source columns rather than silently merged.
