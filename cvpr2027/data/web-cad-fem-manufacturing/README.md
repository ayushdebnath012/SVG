# Published CAD/FEM collection extension

Two original FreeCAD CAD documents with saved numerical FEM fields downloaded from TimSwait-AMRC’s FreeCAD pull request https://github.com/FreeCAD/FreeCAD/pull/28380. One unbalanced asymmetric two-ply laminate case (0/45 degrees, 1 mm each) and one basic isotropic Code_Aster/CalculiX comparison; three saved solutions, two cases. Native BREP validity and finite displacement arrays verified. CAD inspection figures tessellate original BREP; CSVs extract unchanged saved arrays by source array index (not verified node IDs). No CAD or FEM solution generated locally.

These are candidates, not admitted benchmark cases. The laminate source has touched solver/mesh/result flags. Review units and native model/result correspondence before scoring. Original attachment does not establish a standalone data license; file metadata has a default All rights reserved value. Preserve attribution and clarify public redistribution separately from local research collection.

Hannover milling source includes five STEP members, an original dimensioned drawing and measurement comparisons. Kept as a held lead, not FEM ground truth. Dataset source and license are recorded in catalog.json and original download metadata.

Do not count solver outputs, plies, mesh nodes or measurement images as separate tasks. No frontier model trials or accuracy scores have been run.
