# IC Engine Design and Static Structural Analysis

## Overview
This project focuses on the 3D modeling and assembly of a complete Internal Combustion (IC) Engine using SOLIDWORKS. The engine consists of key components including the piston, connecting rod, crankshaft, cylinder block, and associated assemblies. To evaluate the structural performance of critical engine components, static structural analysis was performed on the connecting rod ANSYS Simulation.

## Objectives
- Design and assemble a complete IC Engine in SOLIDWORKS.
- Develop detailed 3D models of engine components.
- Analyze the structural behavior of the connecting rod under loading conditions.
- Evaluate stress distribution and deformation characteristics.

## Features
- Complete IC Engine CAD Assembly
- Parametric 3D Modeling
- Engineering Drawings
- Static Structural Analysis
- Stress and Deformation Evaluation

## Software Used
- SOLIDWORKS
- ANSYS Simulation

## Components Modeled
- Piston
- Connecting Rod
- Crankshaft
- Engine Assembly

## Static Structural Analysis
The connecting rod was selected for analysis due to its critical role in transmitting forces between the piston and crankshaft. Static structural analysis was conducted to evaluate:

- Von Mises Stress Distribution
- Total Deformation
- Strain Distribution
- Structural Integrity under Applied Loads

The simulation results were used to assess the component's strength and identify regions experiencing maximum stress concentration.
