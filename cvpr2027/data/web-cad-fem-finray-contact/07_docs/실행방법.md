`AppData\Roaming\Ansys` 에 캐시(`.dat`)가 있어 짧은 유예가 있을 수 있으나
확인되지 않았다. 아래 시험으로 직접 판정할 것.

### 오프라인 판정 시험 (약 1분)

네트워크를 끊고 실행:

```powershell
& $PY -c "from ansys.mapdl.core import launch_mapdl; m=launch_mapdl(exec_file=r'C:\Program Files\ANSYS Inc\ANSYS Student\v261\ansys\bin\winx64\ANSYS261.exe', run_location=r'C:\ANSYS_work\summer4_1_run\offline_test', override=True, nproc=2); m.prep7(); m.et(1,185); m.mp('EX',1,210000); m.mp('PRXY',1,0.3); m.block(0,10,0,1,0,1); m.esize(1); m.vmesh('ALL'); m.nsel('S','LOC','X',0); m.d('ALL','ALL',0); m.nsel('S','LOC','X',10); m.f('ALL','FY',-10); m.allsel(); m.run('/SOLU'); m.solve(); print('OFFLINE OK'); m.exit()"
```

- `OFFLINE OK` → 솔버도 오프라인 가능
- 라이선스 오류 / `capability SOLUTION was not ordered` → 인터넷 필요

## 실행 순서

### 1. 형상 검증 (선택)

```powershell
& $PY 04_scripts\mesh\01_check_geometry.py
```

### 2. 메쉬 생성

```powershell
# 단일핑거 (메쉬 수렴성 확인용)
& $PY 04_scripts\mesh\02_mesh_finray.py --step real15.step --size 1.5 --order 1 --shift-x 0.2896

# 3핑거 (본 해석용)
& $PY 04_scripts\mesh\03_mesh_3finger.py --size 1.5 --shift-x 0.2896
```

`--shift-x 0.2896` 은 초기 간극을 0.735 mm 로 정규화하는 값이다. 빼먹으면
접촉 개시가 0.29 mm 늦어진다.

### 3. 단일핑거 검증 (선택)

```powershell
& $PY 04_scripts\journal\10_single_finger.py --order 1 --size 1.5 --dist 2.10 3.30 4.50
```

### 4. 3핑거 — 인발 시험 (변위 구동)

```powershell
& $PY 04_scripts\journal\20_3finger_capacity.py --close 3.0 4.0 5.0 5.7 --pull 2.0 --pull-dir tip --nsub 40
```

`--pull-dir base` 로 하면 밑동 쪽(중력 방향). 계산만 다시 하지 않고
후처리만 하려면 `--post-only` 를 붙인다.

### 5. 3핑거 — 중력 하중 (본 해석)

```powershell
# 밑동 변위 고정 (형상 구속이 절대적 — 볼이 안 빠짐)
& $PY 04_scripts\journal\21_3finger_gravity.py --gmax 5 --nsub 50 --tilt-deg 10

# 밑동 힘 구동 (실제 액추에이터에 가까움 — 손가락이 벌어질 수 있음)
& $PY 04_scripts\journal\21_3finger_gravity.py --grip-force 2.830 --gmax 3 --nsub 40 --tilt-deg 10
```

주요 인자
- `--gmax` : 몇 kg 상당까지 중력을 램프할지
- `--tilt-deg` : 하중을 손가락 사이 틈 쪽으로 기울이는 각도. 완전 대칭이면
  횡방향 합력이 0 이라 볼이 옆으로 빠지는 모드가 생기지 않는다
- `--grip-force` : 밑동을 변위 고정 대신 이 반경력[N/손가락]으로 잡는다
- `--fix-lateral` : 볼 횡방향을 구속 (기본은 자유)

### 6. 그림 · 애니메이션 · 보고서

## 실행 전 정리 (권장)

학생용 라이선스는 동시 세션이 1개다. 죽은 프로세스가 라이선스를 물면
다음 실행이 실패하므로 먼저 정리한다.

```powershell
Get-Process | Where-Object { $_.ProcessName -match 'ANSYS(261)?$' } | Stop-Process -Force
Get-ChildItem "C:\ANSYS_work\summer4_1_run" -Recurse -Filter "file.lock" | Remove-Item -Force
```

각 해석 스크립트도 시작 시 같은 정리를 수행하지만, 수동으로 해두면 확실하다.

## 진행 상황 확인

해석이 오래 걸릴 때 (수 시간) 다음으로 상태를 본다.

```powershell
# 수렴 이력 — 서브스텝이 늘어나면 진행 중
Get-Content "C:\ANSYS_work\summer4_1_run\case_gravity\file.mntr" -Tail 5

# 오류
Get-Content "C:\ANSYS_work\summer4_1_run\case_gravity\file0.err" -Tail 30
```

`file.mntr` 이 몇 분째 갱신되지 않으면 수렴에 실패하며 헛돌고 있는 것이다.
마찰 접촉에서는 `NROPT,UNSYM` 을 빠뜨렸을 때 이렇게 된다.
