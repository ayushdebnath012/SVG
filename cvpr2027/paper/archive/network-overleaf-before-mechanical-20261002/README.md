# ReSolve — CVPR 2027 Overleaf project

Upload: Overleaf -> New Project -> Upload Project -> select `network-overleaf.zip`.
Main document: `main.tex`. Compiler: pdfLaTeX (Overleaf's default; gives the Times font CVPR requires).
XeLaTeX and LuaLaTeX also work: `main.tex` then switches to TeX Gyre Termes, a Times clone.

Template: official CVPR author kit (https://github.com/cvpr-org/author-kit): `cvpr.sty`,
`ieeenat_fullname.bst`, `preamble.tex`. Review mode (anonymous, line numbers); for camera-ready
change `\usepackage[review]{cvpr}` to `\usepackage{cvpr}`.

`results.tex` is generated by `scripts/network_paper_results.py` in the research repository: every
table number comes from saved run artefacts. Edit the script and regenerate instead of editing it here.

Differences from the repository copy (`paper/network/`), for Overleaf compatibility only:
- engine-dependent font setup in `main.tex` (Times under pdfLaTeX, TeX Gyre Termes otherwise);
- the Omega and slashed-O characters inside the appendix prompt listing are escaped for pdfLaTeX;
- only the figures the paper uses are included (PDF/PNG; editable SVG sources stay in the repository).
