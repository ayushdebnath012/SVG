\section{Introduction}
\label{sec:intro}
A request to enlarge a bore, remove a bracket flange or add a blind shaft slot changes one part of a CAD construction while preserving the remaining shape. Figure~\ref{fig:benchcad-reference} illustrates released source/target pairs. Program execution alone does not determine whether the requested edit was made: a valid solid may have the wrong feature dimensions or locations.

We implement \ours as a patch-editing and repair workflow around a frozen Astra model. The model receives source CAD, an instruction and permitted observations; it emits a typed patch against the original source. Execution produces the edited solid. When a check fails, a diagnosis conditions a replacement patch, which is again applied to the original source and re-evaluated. Search can explore alternative interpretations, backtrack and retain multiple candidates.

The central empirical question is whether target-free verification provides enough information to select better patches. We examine experience retrieval, diverse hypotheses, MCTS, Pareto selection, rendered-view judgement and conditional physical checks. In the recorded BenchCAD experiment, these components do not improve the initial \pipeAstra/\pipeN{} strict matches: the full configuration reaches \pipeFull/\pipeN{}. Many incorrect answers satisfy the available checks, while some correct answers fail them.

\paragraph{Contributions.}
\begin{itemize}
\item An executable Astra-guided CAD patch-repair pipeline with original-source indexing, structured failure diagnoses and bounded graph exploration.
\item A staged evaluation of retrieval, search and verification on a fixed local BenchCAD holdout, reporting recoveries, regressions, call counts and costs.
\item An explicit separation between geometry validity, instruction proxies, scenario-defined physical checks and offline agreement with released reference solids.
\end{itemize}
The contribution is an implemented workflow and empirical evaluation. Neither stronger general editing performance nor physical certification is established by the current experiment.
